# Online-Store-React

A frontend ecommerce web application built using React.js.  
This project focuses on creating a multi-page user interface, routing, and component-based architecture for an online shopping experience.

## 🚀 Features
- Multiple screens using React Router
- Reusable and modular React components
- Responsive UI using CSS
- Organized project structure
- Clean and user-friendly interface

## 🛠️ Technologies Used
- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- React Router
- Git & GitHub
- VS Code

## 📂 Project Structure
src/ ├── components/ ├── screens/ ├── images/ ├── context/ ├── App.js ├── index.js
